# 🚀 NIC Converter — Sri Lankan NIC Parser

A lightweight and fast tool to **parse Sri Lankan NIC numbers** and instantly extract:

- 🎂 **Date of Birth**  
- 🚻 **Gender**  

Whether it’s the **old NIC format** (e.g., `921234567V`) or the **new NIC format** (e.g., `200112345678`), this tool decodes everything in **seconds**!

---

## ✨ Features

✅ **Supports Old & New NIC Formats**  
- OLD: `YYDDDXXXXV`  
- NEW: `YYYYDDDXXXXX`  

✅ **Extracts Information Automatically**  
- Date of Birth  
- Gender (Male / Female)  

⚡ **Ultra-fast Performance**  
- Built with **Vite + Vanilla JavaScript**  
- No heavy dependencies  
- Lightweight, clean, and efficient  

🎨 **Simple & Modern UI**
